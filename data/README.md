# Downloading Data
The primary dataset can be found at https://www.kaggle.com/datasets/yassereleraky/aviation-accident-ntsb/data?select=NTSB_database.csv

To download the data from Kaggle, you will need to have a Kaggle account and either set up the Kaggle API or download the dataset zip archive.

All data files are ignored with git so changes will not be tracked in this directory.
